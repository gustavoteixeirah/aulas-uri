caderno dropna

O comando que apaga tudo

>>> titanic.shape
(891, 12)
>>> titanic.dropna().shape  # sem argumento nenhum
(183, 12)  # 79% da tabela foi embora
>>> titanic.dropna(subset=["Embarked"]).shape  # só quem importa
(889, 12)
>>> titanic.dropna(thresh=11).shape  # exige 11 colunas cheias
(733, 12)
Basta uma cabine em branco para a linha inteira sair. É o erro mais comum da limpeza: resolver o faltante destruindo o dataset.

Quase sempre o certo é subset=: derrube a linha só quando falta o que você vai usar.

caderno fillna

Cada coluna com a sua regra

✗ O atalho

titanic.fillna(0)

Cabine vira zero. Idade vira recém-nascido. Porto de embarque vira zero.

✓ O honesto

titanic.fillna({
    "Age": titanic["Age"].median(),
    "Embarked": "S",
    "Cabin": "sem registro",
})

Uma decisão declarada por coluna.

O dicionário obriga você a pensar coluna por coluna — que é exatamente o trabalho.
caderno Assimetria · skew

Média ou mediana?

Na idade, skew 0,39 — tanto faz. No salário, skew 7,16: a média é 11.821 e a mediana 7.870. A regra: com |skew| > 1, use a mediana.

Imputar pela média inventa 34 pessoas ganhando 12 mil — e a média sobe de novo.

caderno Gráfico de linhas · ffill × interpolate

O sensor caiu por três horas

O ffill congela a estufa por três horas; o interpolate liga as pontas — o que a física manda.

ffill(limit=2) é o freio de mão: repete duas vezes, e o resto continua buraco.

def chave(s):
    """Texto reduzido ao essencial: sem acento, sem espaço extra, minúsculo."""
    return (s.astype("str")
             .str.normalize("NFKD").str.encode("ascii", "ignore").str.decode("ascii")
             .str.replace(r"\s+", " ", regex=True)
             .str.strip().str.lower())

limpo = (sem_dup.assign(_k=chave(sem_dup["cliente"]))

caderno A cascata

Um formato de cada vez

def para_data(s, formatos=("%Y-%m-%d", "%d/%m/%Y", "%d-%m-%Y")):
    """Tenta cada formato explícito, na ordem; só mexe no que ainda está vazio."""
    saida = pd.Series(pd.NaT, index=s.index, dtype="datetime64[us]")
    for f in formatos:
        pendente = saida.isna() & s.notna()
        saida[pendente] = pd.to_datetime(s[pendente], format=f, errors="coerce")
    return saida
1. Listeos formatos que o arquivo tem
2. Convertaum por vez, format= explícito
3. Confiramin e max contra o negócio
O passo 3 pega 30 das 112; as outras 82 ficam ali, plausíveis e erradas. Conferir a faixa é obrigatório — confiar só nela, não.

IQR

q1, q3 = s.quantile(.25), s.quantile(.75)
iqr = q3 - q1

O corpo dos dados vai do primeiro ao terceiro quartil. A mais de 1,5 amplitudes dele, é candidato — a regra dos pontinhos do boxplot.

O 1,5 é convenção, não lei.

caderno z-score · MAD

A régua que o outlier entorta

z comum

(s - s.mean()) / s.std()

Usa média e desvio — o que o outlier estraga.

4 pedidos com |z| > 3

z robusto (MAD)

0.6745 * (s - s.median()) /
    (s - s.median()).abs().median()

Usa mediana — que não se move.

83 pedidos com |z| > 3

A maior venda tem z 14,2 e z robusto 151: o z comum foi cegado pelos próprios outliers, que incharam a régua dele.

caderno loc · iloc

Rótulo ou posição

>>> df.loc["b"]       # pelo RÓTULO do índice
>>> df.iloc[1]       # pela POSIÇÃO

>>> df.loc["b":"d"]   # ['b', 'c', 'd'] — INCLUI o fim
>>> df.iloc[1:3]     # ['b', 'c']      — EXCLUI o fim
A fatia do loc inclui o último; a do iloc exclui. É o bug clássico de um item a mais ou a menos.
caderno Copy-on-Write · pandas 3

Escrever numa fatia não muda o original

>>> caros = df[df["liquido"] > 1000]
>>> caros["liquido"] = 0  # sem erro, sem aviso
>>> df["liquido"].max()
157051.98  # o original está intacto
Até o pandas 2 vinha o SettingWithCopyWarning, e o resultado era imprevisível. No pandas 3 o Copy-on-Write é o padrão: o aviso sumiu porque a regra ficou firme.

Para alterar o original

df.loc[condição, "col"] = valor

Para trabalhar à parte

novo = df[condição].copy()
